# Site Institucional - Dr. José Carlos Cardoso Ribeiro e IAJ

Site institucional responsivo em HTML, CSS e JavaScript puro para apresentar:

- Dr. José Carlos Cardoso Ribeiro
- Atuação jurídica
- Biografia e trajetória
- IAJ - Instituto de Atualização Jurídica
- Conteúdos e canais oficiais
- Contato por WhatsApp

## Alunos aprovados do IAJ

As imagens dos aprovados ficam em `assets/images/aprovados`.

Para adicionar um novo aluno aprovado, copie a imagem para essa pasta e replique um card da seção `aprovados-iaj` no `index.html`, preenchendo nome, selo e concurso apenas com dados confirmados.

## Observações

O projeto evita dados não confirmados. Biografia, áreas de atuação, cursos, endereço, horários, fotografia e logotipo do IAJ devem ser validados antes da publicação definitiva.

O site é estático e pode ser publicado no GitHub Pages, Netlify ou hospedagem convencional.
